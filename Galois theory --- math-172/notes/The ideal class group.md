Let $\mathbb{K} = \mathbb{Q}(\sqrt{ d })$ be an [[Galois theory --- math-172/notes/Quadratic number fields#_definition _ (real, imaginary) quadratic number fields|imaginary quadratic number field]]. Let $\mathscr{O}_{\mathbb{K}}$ be its ring of integers.

The *idea* of the ideal class group is that we can form a by multiplying ideals. Modding out by the action of principal ideals will allow us to measure how far the ring is from being a PID, and thus, a UFD. That is, it measures how far the ring is from being *ideal*.

It's obvious that ideals form a monoid (with identity $(1)$) under multiplication. We call this the **ideal class nonoid**.

##### _example:_ ideal multiplication in $\mathbb{Z}[\sqrt{ -5 }]$

$\mathbb{Z}[\sqrt{ -5 }]$ is not a UFD because $6 = 2 \times 3 = (1 + \sqrt{ -5 })(1 - \sqrt{ 5 })$. Let the last two be $a, a'$ respectively. Let $\mathfrak{a} = (2, a)$, $\mathfrak{b} = (3, a)$ and define $\mathfrak{a}', \mathfrak{b}'$ similarly. It is not difficult to see that the idea product is $\mathfrak{a} \mathfrak{a}' = (2)$ and $\mathfrak{b} \mathfrak{b}' = (3)$. Also, $\mathfrak{a} \mathfrak{b} = (a)$ and $\mathfrak{a}' \mathfrak{b}' = (a')$. Finally $\mathfrak{a} \mathfrak{a}' \mathfrak{b} \mathfrak{b}' = (6)$.

The idea is that unique factorisation failed in $\mathbb{Z}[\sqrt{ -5 }]$ because we can factor some principal primes into non-principal primes. In particular, one can show using [[Galois theory --- math-172/notes/Geometry of numbers#_lemma _ points in the lattice must be sufficiently far away|facts about lattices]] that every ideal $\mathfrak{a} \subseteq \mathbb{Z}[\sqrt{ -5 }]$ is either $\alpha$ and then generated by $\alpha, \alpha \sqrt{ -5 }$ as a lattice, or is not principal and is generated by $\alpha, \alpha (1 + \delta) / 2$ as a lattice.

Note, in this example $\mathfrak{a} = \mathfrak{a}'$ but this is not always true.

##### _lemma:_ ideal multiplication almost has inverses

If $\mathfrak{a} \subseteq A = \mathscr{O}_{\mathbb{K}}$ is a non-zero ideal, then there is another ideal $\mathfrak{b} \subseteq A$ such that $\mathfrak{a} \mathfrak{b} = (n)$ for some $n \in \mathbb{Z}$.

###### _proof:_

Since $\mathfrak{a} \subseteq A$, it is a rank $2$ lattice. Suppose it is generated by $\alpha, \beta$ as a lattice. Consider, $\mathfrak{b} = (\overline{\alpha}, \bar{\beta})$. Then $\mathfrak{a} \mathfrak{b} = (\alpha \bar{\alpha}, \beta \bar{\beta}, \alpha \bar{\beta}, \bar{\alpha} \beta)$. Note that the first two, and the sum of the last two are in $\mathbb{Z}$. Call these three integers $a, b, c$. 

Consider $n = \gcd(a, b, c)$. Clearly $(n) \subseteq \mathfrak{a} \mathfrak{b}$. Conversely, we can show each generator is a multiple of multiple of $n$. For $a$ and $b$ this is easy since they are already integers. Write $\gamma = \alpha \bar{\beta} / n \in \mathbb{Q}(\sqrt{ d })$ and define $\overline{\gamma}$ similarly. These are roots of a monic polynomial $(x - \gamma)(x - \bar{\gamma}) = x^{2} - (\gamma + \overline{\gamma}) x + \bar{\gamma}\gamma$ with integer coefficients $1, \gamma + \overline{\gamma} = c / n$, and $\bar{\gamma}\gamma / n^{2} = ab / n^{2}$. Thus, they are algebraic integers — $n \mid \alpha \bar{\beta}, \bar{\alpha} \beta$.

##### _corollary:_ the ideal class monoid is cancellative

Suppose $\mathfrak{a}, \mathfrak{b}, \mathfrak{c}$ are non-zero ideals in $\mathscr{O}_{\mathbb{K}}$. Then $\mathfrak{a} \mathfrak{b} \subseteq \mathfrak{a} \mathfrak{c}$ if and only if $\mathfrak{b} \subseteq \mathfrak{c}$. Thus, $\mathfrak{a} \mathfrak{b} = \mathfrak{a} \mathfrak{c}$ if and only if $\mathfrak{b} = \mathfrak{c}$.

In particular, the commutative monoid of ideals under ideal multiplication is cancellative.

###### _proof:_

Clearly, if $\mathfrak{b} \subseteq \mathfrak{c}$, then $\mathfrak{a} \mathfrak{b} \subseteq \mathfrak{a} \mathfrak{c}$ follows.

Suppose $\mathfrak{a} \mathfrak{b} \subseteq \mathfrak{a} \mathfrak{c}$. Let $\mathfrak{a}\mathfrak{a}' = (n)$ for $n \in \mathbb{Z}$. Then $(n) \mathfrak{b} \subseteq (n) \mathfrak{c}$. One can check explicitly that multiplication by $n$ is cancellative. One way to do this is to multiply by $1 / n$ and look at the sublattices you get.

---

##### _corollary:_ subideals are multiples of their superideals

$\mathfrak{a} \subseteq \mathfrak{b}$ is a subideal if and only if $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$ for some $\mathfrak{c}$. 

###### _proof:_

Clearly, if $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$, then $\mathfrak{a} = \mathfrak{b} \mathfrak{c} \subseteq \mathfrak{b}$.

Suppose $\mathfrak{b} = (\beta)$ is principal. If $\mathfrak{a} \subseteq \mathfrak{b}$, then $\beta$ divides every element of $\mathfrak{a}$. Consider the sublattice $\mathfrak{c} = \beta^{-1} \mathfrak{a} \subseteq \mathscr{O}_{\mathbb{K}} \subseteq \mathbb{K}$. In fact, $\mathfrak{c}$ is an ideal of $\mathscr{O}_{K}$ and $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$.

Now suppose $\mathfrak{a} \subseteq \mathfrak{b}$ for $\mathfrak{b}$ non-principal. Let $\mathfrak{b} \mathfrak{b}' = (n)$. Then multiplying by $\mathfrak{b}'$ gives $\mathfrak{a} \mathfrak{b}' \subseteq (n)$ and so $\mathfrak{a} \mathfrak{b}' = \mathfrak{b} \mathfrak{b}' \mathfrak{c}$. Cancelling $\mathfrak{b}'$ gives $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$.

---

This is a really important result to show that the number rings $\mathscr{O}_{\mathbb{K}}$ are nice — [[Galois theory --- math-172/notes/Quadratic number fields#_theorem _ imaginary quadratic number rings are Dedekind domains|they are]] [[Galois theory --- math-172/notes/Dedekind domains|Dedekind domains]].

##### _definition:_ ideal class group

The **ideal class group** of $\mathscr{O}_{\mathbb{K}}$ is is the group completion of the ideal class monoid modulo the subgroup of principal ideals. We write it as $\operatorname{cl} \mathscr{O}_{\mathbb{K}}$.

Equivalently, it is the ideal class monoid modulo the submonoid of principal ideals (since we can always write $\mathfrak{a} \mathfrak{b} = (n)$).

---

##### _theorem:_ the ideal class group is finite

The ideal class group $\operatorname{cl} \mathscr{O}_{\mathbb{K}}$ is finite for any imaginary quadratic number ring.

### Computing the class group

One useful tool that we have to compute the class group is a notion of "size" for the ideal.

##### _definition:_ norm of an ideal

The **norm** of an ideal $\mathfrak{a} \subseteq \mathscr{O}_{\mathbb{K}}$ is $N(\mathfrak{a})$, the smallest integer such that $\mathfrak{a} \mathfrak{b} = (n)$.

---

Note, the norm of a principal ideal agrees with the norm of its generator.

##### _proposition:_ various conceptions of size agree

Suppose $\mathfrak{a} \subseteq A = \mathscr{O}_{\mathbb{K}}$. Then 
$$
N(\mathfrak{a}) = A : \mathfrak{a} = \frac{\Delta(\mathfrak{a})}{\Delta(A)}
$$
and for
$$
\mu = \begin{cases}
\frac{2}{\sqrt{ 3 }} \sqrt{ \lvert d \rvert  } & d = 2, 3 \pmod 4 \\
\frac{1}{\sqrt{ 3 }} \sqrt{ \lvert d \rvert  }
\end{cases}
$$
we have $\min_{\alpha \in \mathfrak{a}} N(\alpha) \leq \mu N(\mathfrak{a})$.

###### _proof:_

We just give the proof of the last inequality. In either of the cases, $\mu = 2 \Delta(A) / \sqrt{ 3 }$. [[Galois theory --- math-172/notes/Geometry of numbers#_proposition _ bounding minimal length vectors|We have a bound]] on the length of the minimum length vector in a lattice. Specifically, $\min_{\alpha \in \mathfrak{a}} N(\alpha) \leq \frac{2}{\sqrt{ 3 }} \Delta(\mathfrak{a}) = \mu N(\mathfrak{a})$.

---

This allows us to show the following.

##### _theorem:_

1) Every ideal class in $\operatorname{cl} \mathscr{O}_{\mathbb{K}}$ contains an ideal $\mathfrak{a}$ such that $N(\mathfrak{a}) \leq \mu$.
2) $\operatorname{cl} \mathscr{O}_{\mathbb{K}}$ is generated by classes of prime ideals $\mathfrak{p}$ with norm $N(\mathfrak{p}) \leq \mu$.
3) $\operatorname{cl} \mathscr{O}_{\mathbb{K}}$ is finite.

###### _proof:_

(2) follows from (1) since $\mathscr{O}_{\mathbb{K}}$ is a Dedekind domain and norm is multiplicative. (3) follows from (2) — there can only be finitely many such generators.

Suppose $\mathfrak{a} \subseteq \mathscr{O}_{\mathbb{K}}$ is an ideal. Choose $\alpha \in \mathfrak{a}$ with $N(\alpha) \leq \mu N(\mathfrak{a})$. Since $(\alpha) \subseteq \mathfrak{a}$, we have $(\alpha) = \mathfrak{a} \mathfrak{c}$. Since norm is multiplicative, we have $N(\mathfrak{c}) \leq \mathfrak{u}$. Since $\mathfrak{a} \mathfrak{c}$ is principal, $\mathfrak{c}$ is in the ideal class of the multiplicative inverse of $\mathfrak{a}$. Every ideal class is the multiplicative inverse of some $\mathfrak{a}$, so we are done.

---

##### _example:_ proving a number ring is a PID

Consider $\mathbb{K} = \mathbb{Q}(\sqrt{ -7 })$. Then $\mu = \sqrt{ 7 / 3 } \approx 1.52$. But there are no prime integers so small, and thus, there are no primes lying above them with small enough norm either. Thus, $\mathscr{O}_{\mathbb{K}}$ is a PID.

---

##### _example:_ a harder example

Consider $\mathbb{K} = \mathbb{Q}(\sqrt{ -163 })$ now. Then $\lfloor \mu \rfloor = 7$. We only need to check for primes lying above $p = 2, 3, 5, 7$. Then check that $x^{2} - x + h$ is irreducible above all these primes.

---

##### _example:_ proving a number ring is not a PID

Consider $\mathbb{K} = \mathbb{Q}(\sqrt{ -26 })$. $\lfloor \mu \rfloor = 5$. $2$ ramifies, $3$ splits, and $5$ splits. Thus, the primes lying over could have small enough norm
