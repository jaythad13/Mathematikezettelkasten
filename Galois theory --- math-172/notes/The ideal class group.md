The *idea* of the ideal class group is that we can form a group by multiplying ideals. Modding out by the action of principal ideals will allow us to measure how far the ring is from being a PID, and thus, a UFD. That is, it measures how far the ring is from being *ideal*.

##### _example:_ ideal multiplication in $\mathbb{Z}[\sqrt{ -5 }]$

$\mathbb{Z}[\sqrt{ -5 }]$ is not a UFD because $6 = 2 \times 3 = (1 + \sqrt{ -5 })(1 - \sqrt{ 5 })$. Let the last two be $a, a'$ respectively. Let $\mathfrak{a} = (2, a)$, $\mathfrak{b} = (3, a)$ and define $\mathfrak{a}', \mathfrak{b}'$ similarly. It is not difficult to see that the idea product is $\mathfrak{a} \mathfrak{a}' = (2)$ and $\mathfrak{b} \mathfrak{b}' = (3)$. Also, $\mathfrak{a} \mathfrak{b} = (a)$ and $\mathfrak{a}' \mathfrak{b}' = (a')$. Finally $\mathfrak{a} \mathfrak{a}' \mathfrak{b} \mathfrak{b}' = (6)$.

The idea is that unique factorisation failed in $\mathbb{Z}[\sqrt{ -5 }]$ because we can factor some principal primes into non-principal primes.

Note, in this example $\mathfrak{a} = \mathfrak{a}'$ but this is not always true.

An important lemma

##### _lemma:_ ideal multiplication almost has inverses

Let $\mathbb{K} = \mathbb{Q}(\sqrt{ d })$ be a quadratic imaginary number field. If $\mathfrak{a} \subseteq A = \mathscr{O}_{\mathbb{K}}$ is a non-zero ideal, then there is another ideal $\mathfrak{b} \subseteq A$ such that $\mathfrak{a} \mathfrak{b} = (n)$ for some $n \in \mathbb{Z}$.

###### _proof:_

Since $\mathfrak{a} \subseteq A$, it is a rank $2$ lattice. Suppose it is generated by $\alpha, \beta$ as a lattice. Consider, $\mathfrak{b} = (\overline{\alpha}, \bar{\beta})$. Then $\mathfrak{a} \mathfrak{b} = (\alpha \bar{\alpha}, \beta \bar{\beta}, \alpha \bar{\beta}, \bar{\alpha} \beta)$. Note that the first two, and the sum of the last two are in $\mathbb{Z}$. Call these three integers $a, b, c$. 

Consider $n = \gcd(a, b, c)$. Clearly $(n) \subseteq \mathfrak{a} \mathfrak{b}$. Conversely, we can show each generator is a multiple of multiple of $n$. For $a$ and $b$ this is easy since they are already integers. Write $\gamma = \alpha \bar{\beta} / n \in \mathbb{Q}(\sqrt{ d })$ and define $\overline{\gamma}$ similarly. These are roots of a monic polynomial $(x - \gamma)(x - \bar{\gamma}) = x^{2} - (\gamma + \overline{\gamma}) x + \bar{\gamma}\gamma$ with integer coefficients $1, \gamma + \overline{\gamma} = c / n$, and $\bar{\gamma}\gamma / n^{2} = ab / n^{2}$. Thus, they are algebraic integers — $n \mid \alpha \bar{\beta}, \bar{\alpha} \beta$.

##### _corollary:_ the ideal class monoid is cancellative

Suppose $\mathfrak{a}, \mathfrak{b}, \mathfrak{c}$ are non-zero ideals in $\mathscr{O}_{\mathbb{K}}$. Then $\mathfrak{a} \mathfrak{b} \subseteq \mathfrak{a} \mathfrak{c}$ if and only if $\mathfrak{b} \subseteq \mathfrak{c}$. Thus, $\mathfrak{a} \mathfrak{b} = \mathfrak{a} \mathfrak{c}$ if and only if $\mathfrak{b} = \mathfrak{c}$.

In particular, the commutative monoid of ideals under ideal multiplication is cancellative.

###### _proof:_

Clearly, if $\mathfrak{b} \subseteq \mathfrak{c}$, then $\mathfrak{a} \mathfrak{b} \subseteq \mathfrak{a} \mathfrak{c}$ follows.

Suppose $\mathfrak{a} \mathfrak{b} \subseteq \mathfrak{a} \mathfrak{c}$. Let $\mathfrak{a}\mathfrak{a}' = (n)$ for $n \in \mathbb{Z}$. Then $(n) \mathfrak{b} \subseteq (n) \mathfrak{c}$. One can check explicitly that multiplication by $n$ is cancellative. One way to do this is to multiply by $1 / n$ and look at the sublattices you get.

##### _corollary:_ subideals are multiples of their superideals

$\mathfrak{a} \subseteq \mathfrak{b}$ is a subideal if and only if $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$ for some $\mathfrak{c}$. 

###### _proof:_

Clearly, if $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$, then $\mathfrak{a} = \mathfrak{b} \mathfrak{c} \subseteq \mathfrak{b}$.

Suppose $\mathfrak{b} = (\beta)$ is principal. If $\mathfrak{a} \subseteq \mathfrak{b}$, then $\beta$ divides every element of $\mathfrak{a}$. Consider the sublattice $\mathfrak{c} = \beta^{-1} \mathfrak{a} \subseteq \mathscr{O}_{\mathbb{K}} \subseteq \mathbb{K}$. In fact, $\mathfrak{c}$ is an ideal of $\mathscr{O}_{K}$ and $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$.

Now suppose $\mathfrak{a} \subseteq \mathfrak{b}$ for $\mathfrak{b}$ non-principal. Let $\mathfrak{b} \mathfrak{b}' = (n)$. Then multiplying by $\mathfrak{b}'$ gives $\mathfrak{a} \mathfrak{b}' \subseteq (n)$ and so $\mathfrak{a} \mathfrak{b}' = \mathfrak{b} \mathfrak{b}' \mathfrak{c}$. Cancelling $\mathfrak{b}'$ gives $\mathfrak{a} = \mathfrak{b} \mathfrak{c}$.

---

##### _definition:_ ideal class group

The **ideal class group** is the group completion of the ideal class monoid.
